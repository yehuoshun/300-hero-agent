## 2026-11-19 20:36 · 局内输入测试：键盘进得去，右键移动没生效

- 动作：`shot` → `key esc` → `shot` → 帧差；再 `click at 0.50 0.70 right` → 帧差；再 `key q` → 帧差
- 数据：ESC 后整帧差 `mean=24.92, 大变化像素 25.38%`；右键移动后 `mean=1.72, 1.07%`；

  （也没出现技能特效）。三种可能，下一局要逐个排掉：① 相机是自由的（没锁在英雄身上），
  英雄动了但屏幕没动、我的点击其实点在了离英雄很远的地方；② 当时英雄已死（本局 0/1/0，
  确实死了一次）；③ 这游戏移动不是右键（待确认）。
  另外 `state` 里 `hp: null` 说明「血量读不到」**不能**当死亡判据——截图被结算面板盖住时也读不到。

  移动后的 `p2` 里在 (1472,696) ≈ **(0.575, 0.483)**，脚底大约压在 0.5 上下
- 结论：① **右键点地面能走**，之前那次 1.7% 帧差是因为英雄当时已死（死后相机可自由拖，点地面没反应）；
  ② 相机是跟英雄的，但横向会有最多约 8% 屏宽的提前/滞后，垂直稳定在 0.48 → 说「自己就在正中」
  只对了一半，真要用得**每帧估**，不能写死 0.5；
  ③ `state` 报的 `me: [0.5,0.5]` 目前是硬编码，属于假信息，别拿它做判断。
