### 权限：为什么有个常驻桥

每条命令都自提权＝每次都弹 UAC，会把人的注意力反复扯断（用户的抱怨）。
所以做了一次性提权：`src/bridge.py` 常驻在 `127.0.0.1:52341`，UAC **只弹一次**，
之后所有点击/按键/抓图/对局循环都从这个提权进程里发；非提权侧用 `tools/ctl.py` 发一行
JSON、收一行 JSON。

```powershell
# 起桥（自己提权，隐藏控制台；UAC 点一次「是」）
.\.venv\Scripts\python.exe src\bridge.py --serve --hidden
# 之后
.\.venv\Scripts\python.exe tools\ctl.py ping     # {"ok": true, "admin": true, "port": 52341}
.\.venv\Scripts\python.exe tools\ctl.py state
.\.venv\Scripts\python.exe tools\ctl.py shot tmp\a.png
.\.venv\Scripts\python.exe tools\ctl.py click ui popup_close
.\.venv\Scripts\python.exe tools\ctl.py click at 0.52 0.53      # 相对比例
.\.venv\Scripts\python.exe tools\ctl.py key w
```

## 3. 已知坑（每条都吃过一次）

1. **抓图必须紧跟 focus**。提权版 `src/input.py --shot` 是 `click` → sleep `ui.click_settle=4.0`
   → `grab()`，这 4 秒里前台被别的窗口抢走，存下来的图是 DSH 聊天界面而不是游戏。
   → 现在 bridge 的 `shot` 是「focus 后立刻 grab」，并在回包里带 `focus` 字段给调用方自检。
2. **红条数不能当「在对局里」的判据**。大厅（明明没进对局）`state` 就报了 `red_bars=2`，
   血量读数是 `null`（`hp_note` 说明血条轨道没找到）。判断是否在对局，得看血条可读性 +
   小地图/技能栏这些只在局内出现的东西。
3. **ESC 不是返回**。选英雄页按 ESC 回大厅并弹系统设置（X 在 `settings_close 0.807, 0.2025`），
   自动化里别拿 ESC 当「后退」。
4. **不要点商城/英雄/装备页**。顶栏「主页 英雄 商城 活动 日常 装备 修仙 社团」在 y≈0.03，
   误点一次就可能买错东西或拆掉装备——用户明令禁止。

## 7. 天道战场怎么打（资料 + 实测对齐）

官方**没有**出过天道战场的玩法文字稿（官网公告正文基本是长图），所以下面每条都标了来源强弱。

**✅ 实测（第一局 2026-11-19，21:33 结束 → 失败 977 : 3000）**

- **胜负＝分数制，先到 3000 分**。敌方正好停在 3000，我方 977。
- 局内顶部有比分和**两个倒计时**（一个是阶段倒计时，一个是回合/其它计时）。
- 左侧阶段面板显示的阶段名：**灵魂收集阶段** → **进击阶段** →（结束后）**休息阶段**，循环。
- 灵魂收集阶段文案：*在野外收集灵魂 → 前往祭坛提交，可强化英雄祭品*；
  **每提交 1 个灵魂，本轮进阶段个人获得：最大生命 +1500 / 最大法力 +1500 / 攻击 +40 / 法术强度 +40**；
  未提交的按 50% 折算属性；面板上还有「当前携带 N / 已提交 N」。
- 进击阶段文案：*祭灵者会选择敌方防守最坚固的一条路线进攻；双方所有祭灵者被击杀后阶段结束，
  将进入休息阶段*；面板给出「我方祭灵者 95 / 敌方祭灵者 596」这种数量。
- 右侧两个属性面板：**灵魂属性（本场永久生效）** 与 **灵魂结晶属性（本论进阶段生效）**，
  条目为 生命/法力/攻击/法强/暴击率/移动速度/生命偷取/法术吸血——都从 0 开始涨。

**⚠️ 玩家攻略说的（B 站 up 主，非官方）**

- 塔很硬且带 debuff，**不拆三路高地塔上高地就是被秒**，别玩速推。
- 大小龙 Boss 会掉可拾取的属性；**灵魂石要交上去**，数值极高（原话「多捡你就是赛博超人」）。
- 靠击杀拿分快（有人做「7 分钟速通」），说明分数主要来自击杀/推塔而非苟着。
- 有野区，可以刷。

**❓ 还不知道**：官方人数（实测双方各 7 人）、是否有 AI 填充、分数细则（击杀/推塔各多少分）、
复活机制（道具可复活？）、符文/天赋在局内是否生效。

**给新手的务实路线**（我自己第一局 0/1/0 的教训）：先活下来 → 跟团 → 捡灵魂并交到祭坛 →
别单带塔。得分靠击杀，但送人头也会给对方送分。

## 8. 局内输入/相机（已排查到能用的程度）

- ✅ **键盘进得去**：按 `esc` 后整帧差 25% 像素（弹出界面），说明提权链路 OK。
- ✅ **右键点地面能走**：点 (0.58, 0.54) 后整帧相位相关位移 `dx=+270, dy=-135`，
  1.2 秒后位移归零（相机停住＝英雄到点）。之前测出「右键无效」是因为**当时英雄已死**。
- ✅ **相机跟英雄，但不是死锁正中**：静止时英雄名牌在 (0.500, 0.483)；
  移动后同一帧测到 (0.575, 0.483)——横向最多有约 8% 屏宽的提前/滞后，垂直稳定在 0.48。
  → 要用「我在哪」时**每帧估**，别信 `perceive.self_position()`（现在硬编码 0.5,0.5，是假的）。
- ❌ **`find_red_bars` 会把左侧 HUD 面板里的红条当敌人**：连跑 30 拍，候选一直停在
  (208,731)（屏幕最左侧）一动不动。修法：只接受中央区域（|x-0.5w| < 0.25w，0.15h < y < 0.85h）。
- ⚠️ `hp: null` **不等于死了**：结算面板盖住屏幕时血量也读不到。判死亡要看别的信号。
